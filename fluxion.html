FLUXION

Fluxion is a security auditing and social-engineering research tool. It is a remake of linset by vk496 with (hopefully) less bugs and more functionality. The script attempts to retrieve the WPA/WPA2 key from a target access point by means of a social engineering (phishing) attack.

Installation

$ git clone https://github.com/thehackingsage/fluxion.git $ cd fluxion $ ./fluxion.py

USE

$ cd fluxion $ ./fluxion.py
