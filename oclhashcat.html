OCLHASHCAT

oclHashcat Description. oclHashcat is a GPGPU-based multi-hash cracker using a brute-force attack (implemented as mask attack), combinator attack, dictionary attack, hybrid attack, mask attack, and rule-based attack.

Installation

$ git clone https://github.com/hashcat/hashcat.git $ cd oclHashcat

USE

$./oclHashcat
